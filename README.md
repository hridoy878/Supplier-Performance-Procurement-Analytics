# Supplier Performance & Procurement Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze supplier performance and procurement operations.

The dashboard provides insights into procurement spending, cost savings, supplier reliability, delivery efficiency, product defects, and compliance. It helps identify potential supplier risks and opportunities for procurement optimization.

## Dataset Information

**Dataset:** Procurement KPI Analysis Dataset
**Creator:** Shahriar Kabir
**Source:** Kaggle
**Period:** 2022–2023
**Original Dataset Description:** 700 purchase orders
**Imported Dataset:** 777 records
**Number of Suppliers:** 5

The dataset is publicly available on Kaggle:

[Procurement KPI Analysis Dataset – Kaggle](https://www.kaggle.com/datasets/shahriarkabir/procurement-kpi-analysis-dataset/data)

The dataset contains procurement information, including purchase orders, supplier details, delivery dates, negotiated prices, defective units, and compliance status.

*Note: The dataset description mentions 700 purchase orders, while the CSV imported into this project contains 777 rows.*

## Business Objectives

* Evaluate supplier performance and reliability.
* Analyze total procurement spending.
* Measure savings achieved through price negotiations.
* Monitor delivery efficiency and order status.
* Identify suppliers with higher defect rates.
* Assess supplier compliance.

## Key Performance Indicators (KPIs)

* Total Procurement Spend
* Total Cost Savings
* Total Orders / Records
* Order Delivery Rate
* Average Delivery Days
* Defect Rate

## Dashboard Features

* Procurement Spend by Supplier
* Cost Savings by Supplier
* Purchase Order Status Distribution
* Supplier Defect Rate Comparison
* Average Delivery Time by Supplier
* Interactive date and category filters
* Supplier and compliance filtering
